# Version 1: playset cube

This folder keeps the first version of the Poké Mart Cube.
This version is not in use.

Version 1 had 360 cards with multiple copies of most cards.
Each Stage 2 line had 4 Basic, 3 Stage 1 and 2 Stage 2 cards.
Each Stage 1 line had 3 Basic and 2 Stage 1 cards.
The format was 8 players, 3 packs of 15 cards, 40-card decks and 4 Prize cards.

| File | Contents |
|---|---|
| `index.html` | The version 1 page |
| `cubekoga-import.tsv` | The version 1 CubeKoga import list |
| `cube_list.py` | The version 1 card list |
| `cards.json` | Card text and prices for version 1 (prices from 2026-10-15) |

The build script does not read these files.
